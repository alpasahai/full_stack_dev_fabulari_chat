# 3813ICT - Full Stack Development Assignment

### Assignment Name: full_stack_dev_fabulari_chat
For this assignment, we will be creating a chat system that facilitate user’s communication with each other, passing messages as text and images in real-time. Some users will have elevated privileges to perform administrative functions such as user creation requests, group and channel assignments. 

#### This repository contains: 
    - Code for the Fabulari Application
    - Design Documents - UI designs and Storyboards
    - Phase_1.md: "elicitation of requirements, planning/design and early prototype"
    - Phase_2.md: Full implementation documentation
